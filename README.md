# Complete OK Operations Intelligence Platform

Limited rapid prototype of an autonomous digital workforce platform built for Complete OK Home Health.

**Live demo:** https://vmgcompanies.github.io/complete-ok-prototype/

The live URL serves the final phase (Phase 5). Earlier phases are available alongside it to show the build progression.

## Phases

| Phase | What it adds | URL |
|---|---|---|
| 1 | Brand-locked shell, navigation, static Executive Dashboard | [/complete-ok-phase1.html](./complete-ok-phase1.html) |
| 2 | Live simulation engine driving the dashboard | [/complete-ok-phase2.html](./complete-ok-phase2.html) |
| 3 | Workforce page and Worker Detail Modal | [/complete-ok-phase3.html](./complete-ok-phase3.html) |
| 4 | Patient Operations table and Patient Detail Modal | [/complete-ok-phase4.html](./complete-ok-phase4.html) |
| 5 | Analytics page and final polish | [/complete-ok-phase5.html](./complete-ok-phase5.html) |

## Stack

Single-file HTML per phase. React 18, Babel standalone, Tailwind, Recharts, all loaded from CDN. No build step.

Powered by Neuralogic.
